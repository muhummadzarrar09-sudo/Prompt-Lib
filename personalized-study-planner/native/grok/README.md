# Grok (xAI)

Grok does not have Custom GPTs, Gems, or `SKILL.md`. Teach it with a **system / custom instruction** (Workspaces / custom instructions, depending on the Grok client you have) or paste once at the top of a thread.

## Setup

1. Open Grok.
2. If the client has custom instructions or a workspace system prompt, paste [system.md](./system.md) there.
3. Otherwise paste [system.md](./system.md) as the first message, then your exam details underneath.
4. Stay in that thread. Grok is chatty by default — the prompt clamps that. If it still editorializes, reply `CARD` and continue from the card only.

No knowledge uploads. The rulebook is inlined in `system.md`. If you change `core/RULEBOOK.md`, copy the hard rules through.

## What this pack changes vs the generic rulebook

- Explicit “no takes, no banter, no extra sections”
- Forbids Grok’s habit of offering a second alternative plan
- Tells it not to search X/Twitter for study advice
