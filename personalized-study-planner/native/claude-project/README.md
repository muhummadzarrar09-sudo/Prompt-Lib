# Claude Project (claude.ai)

A **Project** is standing instructions + files for a workspace on claude.ai. A **Skill** is the portable `SKILL.md` pack. Use both if you can: Skill for triggering, Project for the files sitting in the sidebar.

If you only do one: use the Skill ([`../agent-skill`](../agent-skill)) on Claude Code / Skills settings. Use this Project pack when the student will live inside one claude.ai Project until exam day.

## Setup

1. claude.ai → New Project → `Study OS`.
2. Set custom instructions to [instructions.md](./instructions.md).
3. Upload project files:
   - `../../core/RULEBOOK.md`
   - `../../core/output-spec.md`
   - `../../core/card-schema.md`
   - `../../core/priority-and-time.md`
   - `../../templates/study-os-card.md`
   - `../../templates/intake.md`
   - `../../examples/maya-26-days-out.md`
4. Optional: also add the Skill from [`../agent-skill`](../agent-skill) in Skills settings so it triggers in other chats too.
5. Keep **one thread per exam**. Paste the card if the thread gets long.

Claude Projects can see uploaded files more reliably than Custom GPT knowledge. Still print the card every time — that is what the student copies to Notes.
