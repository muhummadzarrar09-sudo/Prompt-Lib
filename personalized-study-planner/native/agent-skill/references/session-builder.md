# Session builder and weak-topic drills

Load this before you print today’s blocks or a weak-topic board.

## Daily session builder

Given today’s available minutes T:

Read `## Profile` and STATE first (`profile.md`). Cap every block at BLOCK minutes.

Always open with 5 minutes closed-book retrieval of yesterday (skip if this is day 1) **unless** START=friction — then open with a 5-min ignition (easiest dump or 3 easy Qs), then recall.

If STATE is fried or low: ignore the week strip tonight. Print a 10–20 min rescue only.

If WEAKHOW=avoid: first real work tick is a weak.
If WEAKHOW=overgrind: cap weaks at 40% of T.

Methods on the tick use STR. TIMED=freeze → first SLICE untimed, PROBE is 3 Qs.

- T ≤ 30: 100% one weak topic. Active recall + 3 questions.
- T 31–60: 60% highest-priority topic, 40% weak drill.
- T 61–120: two blocks. Block A = priority topic (learn or practice). Block B = weak topic + 5 mixed questions. 5–10 min break between.
- T > 120: max three blocks, two subjects max. Last 20 minutes = mixed recall. Mandatory 10-minute break each hour. Do not fill extra time with “read more notes”.

Print TODAY as `- [ ]` ticks, never a paragraph. Each learn/drill tick:

- Clock range
- Precise topic + method
- `Done = __/n` (a number they can put on DONE)
- After: what to update on the card

End with IF THIS DIES (20-min fallback), TOMORROW FIRST, and a DONE stamp.

If they give a start time, use clock ranges. If not, use durations.

## Weak topic protocol

A topic is weak if confidence ≤ 2, they named it, they failed it, or they mix it with another topic.

Store: symptom, error pattern, 15–25 min drill aimed at the symptom (never “review the chapter”), next due, streak.

Spacing: 1d → 3d → 7d → 14d if the drill succeeds. Fail or blank = restart at 1d.

Promote only when confidence ≥ 4 AND a recent quiz or paper section on that topic is mostly correct.

Max 5 active weaks. Park the rest as waiting.
