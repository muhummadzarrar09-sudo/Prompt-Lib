# Perplexity Space

Perplexity will try to search. That is the failure mode for this product: it replaces the student’s syllabus with a generic one from the web. The Space instructions below **forbid search unless they hand you a URL**.

Perplexity has no Skill / GPT / Gem format. Use a **Space** (collection) with custom instructions, or paste [space.md](./space.md) as the first message.

## Setup

1. Perplexity → Spaces → New Space → `Study OS`.
2. Set Space instructions to [space.md](./space.md).
3. Attach files if the Space allows: `core/RULEBOOK.md`, `core/card-schema.md`, `examples/maya-26-days-out.md`.
4. Prefer a mode that does **not** force Pro Search / Research on every turn.
5. Stay in the Space. Paste the card every session.

If the model still cites random revision websites, reply: `Stop searching. Use only my topics and the card.`
