# Modular prompts

Use these if you don’t want the full [`../STUDY-OS.md`](../STUDY-OS.md) sitting at the top of every chat. Each file is a self-contained paste.

| Order | File | When |
|---|---|---|
| 0 | [0-interrogation.md](./0-interrogation.md) | Facts are thin. One question batch. No plan yet. |
| 1 | [1-setup.md](./1-setup.md) | First session. No plan yet. |
| 2 | [2-today.md](./2-today.md) | Every study day. Paste the card. |
| 3 | [3-weak-topics.md](./3-weak-topics.md) | After a test, or when the same topic keeps breaking. |
| 4 | [4-weekly-reset.md](./4-weekly-reset.md) | Once a week. Rebuilds the next 7 days. |
| 5 | [5-exam-countdown.md](./5-exam-countdown.md) | 10 days or fewer. |
| 6 | [6-fell-behind.md](./6-fell-behind.md) | The plan is fiction. 48-hour rescue. |
| 7 | [7-probe.md](./7-probe.md) | Scored diagnostic. Keeps confidence honest. |
| 8 | [8-profile.md](./8-profile.md) | What’s hard, what’s a strength, tonight’s state. Changes the shape of TODAY. |

Recommended path for most students: `1-setup` → `2-today` on loop → `4-weekly-reset` every Sunday → `5-exam-countdown` when the date is close.

If you fell off, skip the guilt and open `6-fell-behind`.
